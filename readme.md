## index.php
1. Tujuan dalam praktikum mempelajari PHP ini untuk mengetahui bagaimana cara membuat web server lokal dan menjalankannya
2. perangkat yang digunakan dalam praktikum ini adalah XAMPP, VSCode, Google Chrome, PHP
3. cara menjalankan server lokal ini:
   - simpan folder proyek di direktori *htdocs*
   - kemudian buka XAMPP lalu jalankan *Apache* dengan klik tombol start

   - buka chrome lalu search *http://localhost/lab7Web/index.php*
